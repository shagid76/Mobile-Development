# Мок-сервер для ПР №3 (варіант 6 — біогазова установка)

Оскільки реального REST API біогазової установки не існує, заняття №10-12
(Retrofit, автентифікація, обробка мережевих помилок) демонструються на
простому мок-сервері Node.js/Express, що імітує поведінку бекенду:
повертає показники реактора у форматі JSON, видає мокований токен при вході
та випадковим чином повертає помилки 500/503 чи "зависає" — щоб можна було
реально побачити роботу retry-логіки та обробки помилок, а не лише код.

## Встановлення та запуск

Потрібен встановлений [Node.js](https://nodejs.org/) (версія 18 або новіша).

```bash
cd mock-server
npm install
npm start
```

Сервер піднімається на `http://localhost:5055` і виводить у консоль список
доступних ендпоінтів.

## Як підключити Android-застосунок до сервера

У файлі `NetworkModule.kt` (`data/remote/NetworkModule.kt`) заданий
`BASE_URL`:

- **Емулятор Android Studio** (за замовчуванням): `http://10.0.2.2:5055/` —
  спеціальна адреса, якою емулятор звертається до `localhost` хост-машини,
  де запущено `npm start`. Нічого змінювати не потрібно.
- **Фізичний пристрій**: замініть `10.0.2.2` на LAN IP-адресу комп'ютера,
  на якому запущено сервер (наприклад, `http://192.168.1.50:5055/`), і
  переконайтеся, що телефон і комп'ютер в одній мережі Wi-Fi.

## Ендпоінти

| Метод | Шлях                 | Опис                                                              |
|-------|-----------------------|--------------------------------------------------------------------|
| GET   | `/readings`           | Список усіх показників реактора                                   |
| GET   | `/readings/:id`       | Один показник за id                                                |
| POST  | `/readings`           | Створити новий показник                                            |
| POST  | `/auth/login`         | Вхід (логін/пароль) → мокований токен + роль                      |
| GET   | `/secure/status`      | Захищені дані (потребує заголовок `Authorization: Bearer <токен>`) |
| GET   | `/unstable/forecast`  | Випадково: успіх / помилка 500 / помилка 503 / "зависання" (12 с) |

## Тестові облікові дані (Заняття №11)

| Логін      | Пароль        | Роль     |
|------------|---------------|----------|
| `admin`    | `admin123`    | ADMIN    |
| `operator` | `operator123` | OPERATOR |

Токен — це НЕ справжній криптографічно підписаний JWT, а навчальна імітація
(`header.payload.signature`, закодована base64url, без підпису) з часом
дії 15 хвилин — саме так, як описано у методичці для мокованої автентифікації.
